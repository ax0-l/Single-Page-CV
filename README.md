# My CV HTML Page

A personal CV page built with semantic HTML, SEO meta tags,
Open Graph tags, and a favicon .

## Features
- Semantic HTML structure (header, main, section, article, footer)
- SEO meta tags (title, description, canonical)
- Open Graph tags for social sharing
- Favicon

## How to Run
1. Download the File Project in your Device and Run it in your Browser.
